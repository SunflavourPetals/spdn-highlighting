# SPDN

A syntax highlighting extension for SPDN (Petals' Data Notation) in VS Code.  

## Features

- Syntax highlighting: comments, strings, numbers, identifiers, `@` constants, etc.
- Error highlighting: invalid numbers, unclosed strings, overlong delimiters, etc.
- Supports three comment styles: `//`, `/* */`, `</ />` (nestable)
- Supports three identifier forms: plain, string, and raw string

## Supported Files

Extension: `.spdn`  

## Usage

After installation, open any `.spdn` file and highlighting will be enabled automatically.  

## About SPDN

SPDN is a Unicode-based data exchange format whose syntax is close to a combination of C++ literals and JSON.
